# Packaging Team

Two specialists: **Carmen Vasquez** (lead, 3yrs) and **Trevor Brooks** (1yr).

**Workflow** (Mon–Fri, 7 AM–3 PM):
1. 6:30 AM — Pull batch tickets from [[Inventory Management]] (Cin7)
2. Weigh/verify roasted coffee against batch yield
3. VFFS bagger: 12oz (retail/sub), 2lb (wholesale), 5lb (foodservice)
4. Nitrogen flush → seal → checkweigh (±1g) → metal detect → label
5. Lot code stamp: YYMMDD-ROASTER-BATCH (e.g., 251104-LOR-03)
6. Case pack: 12×12oz, 6×2lb, 4×5lb
7. Palletize → shrink wrap → staging for [[Inventory Management]] pickup

**Output:** ~1,200 bags/day peak. 99.2% first-pass yield.

**Quality checks:** Hourly seal integrity (water test), weight audit (10%), label legibility.

**Equipment:** [[Equipment]] — VFFS bagger, nitrogen tunnel, checkweigher, labeler.

**Safety:** Lockout/tagout on bagger, hearing protection, ergonomic mats.

Cross-training: Both certified on [[Equipment]] bagger + grinder. Backup from [[Team Structure]] — Diego Rodriguez.
