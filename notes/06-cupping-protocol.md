# Cupping Protocol

Standardized SCA cupping every Tuesday 10:00 AM and Friday 2:00 PM.

**Setup:**
- 8.25g coffee / 150ml water (93°C ±1°)
- 5 cups per sample, 300ml bowls
- Grind: slightly coarser than pour-over (Baratza Forte #18)
- Water: Third Wave Water classic profile (150 ppm TDS)

**Timeline:**
- 0:00 — Pour, start timer
- 4:00 — Break crust, skim, evaluate fragrance/aroma
- 12:00 — First taste pass (flavor, aftertaste, acidity)
- 18:00 — Second pass (body, balance, sweetness)
- 22:00 — Final scoring (uniformity, clean cup, overall)

**Scoring form** (Google Sheets, shared with [[Team Structure]]):
Each attribute 6–10 (quarter-point increments). Defects: taint (-2), fault (-4).

Calibration: Monthly alignment session with Pacific Northwest Cuppers Guild. Marcus maintains Q-Grader cert (renewed 2024).

Data feeds [[Quality Control]] release decisions and [[Signature Series]] selection.
